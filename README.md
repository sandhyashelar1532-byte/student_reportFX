# Student Performance Analytics Studio

An interactive data analytics dashboard built using Python, Pandas, Streamlit, and Plotly.

## Project Overview
This project demonstrates how student performance data can be cleaned, analyzed, visualized, and explored through an interactive dashboard.

## Features
- Data cleaning and preprocessing
- Student performance analysis
- Interactive data visualizations
- Gender-based filtering
- Performance and attendance insights
- Cleaned dataset export in CSV format

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit

## Dataset
A small synthetic student dataset created for demonstration and learning purposes. It does not contain real student records.

## Run Locally

```bash
pip install -r requirements.txt
streamlit run dashboard.py
```

## Project Status
Working prototype — data exploration, visualization, and CSV export implemented.
